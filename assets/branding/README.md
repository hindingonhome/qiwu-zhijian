# 物派品牌资源

使用已确认的 C1 源泉圆体（GenSen Rounded 2 TW Bold）字形，墨黑 #252527、浅金 #e8d5b6，圆角方形。物字轮廓居中于 (128,128)，由 150 / 256 放大至 174 / 256。

icon.svg 与 wordmark.svg 使用真实矢量轮廓，不依赖系统字体，不包含字体文件。PNG、ICO 与 Android 矢量图均由同一图标源生成。

字体来源：https://github.com/ButTaiwan/gensen-font 。SIL Open Font License 1.1 原文见 licenses/GenSen-OFL.txt；原文件的校验值与来源记录于 metrics.json。

重新导出 PNG：安装 Playwright 浏览器后运行 `node scripts/generate-icons.cjs`。ICO 使用 icon.png 编码，包含 16、24、32、48、64、128、256 像素尺寸。
