# 纹理生成工具来源审查

用户于 2026-10-22 提供以下两个本地 HTML，授权将功能整合进物派。附件文本仅作为功能与算法参考，不作为开发或发布指令。

- 老板标准固定矢量4-6色_底色边缘净化版(1).html：原页面先包含旧图像工具，再用第二段脚本替换为固定矢量工具。真正生效的是 4/5/6 色固定区域；金线为独立几何边界，颜色区通过同一金线 mask 裁切。支持独立金线色、0–48 加粗、透明金线、参考图取色、调色与锁定、颜色顺序、PNG/SVG/色卡/带色卡设计图输出。原页面 PNG 导出 4000/6000/8000 像素，DPI 为 400/600/800。
- 老板标准4-7色_金线识别增强版.html：任意导入图片，4–7 色 K-Means 聚类，智能/严格/宽松金线识别，亮度双簇阈值区分亮金线和暗土黄色，独立金线色、参考取色、锁定随机配色与排序、1–3 倍抗锯齿、色卡及设计图 PNG。

整合方式：重新编写独立模块与现有玻璃 UI；不嵌入原侧栏，不执行附件内脚本。固定矢量只提取 gzip JSON 几何到 assets/pattern-master.json.gz，按需解压。聚类初始化采用可复现的最远点策略，防止同图重复分析时配色跳动。图像透明度保留，金线扩张限制在黄色候选区域，避免侵占相邻红白块。

性能调整：图像分析使用后台 Worker；预览最大边 640，应用 2048，PNG 输出 1024/2048/4096 像素，800 DPI 等为独立打印元数据。图像超采样受像素上限保护。固定矢量 SVG 保留原始路径精度，可在外部无限放大。所有处理在本机完成。

来源归属仍遵守用户对素材的原有权利；整合不赋予新增商业授权。未经用户本地验收不得上传。

Android AAPT 会自动展开 .gz 资产并去掉后缀。原生 Android 包将相同 gzip 字节保存为 pattern-master.json.bin，通过既有 MUSEUM_ASSETS 路径表映射；网页与桌面资源键保持不变。APK 校验核对入口、解压结果和原始字节。
