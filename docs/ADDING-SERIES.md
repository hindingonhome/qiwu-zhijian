# 新增系列快捷提示词与操作方法

复制下面这段，替换方括号，再附上模型和配色参考即可：

> 在器物之间主菜单“水果派”旁新增“[系列名称]”系列，按[顺序]收录[器物名称]。模型在[路径]，配色参考在[图片或 PPT 路径]。沿用当前项目规范和已有全部交互、器型、纹样、UV、露铜及交付要求，先检查现有实现，再完成增加、自检和三端离线交付。只在确实缺少关键信息时提问。
>
> 保持原器型比例和细节，不修改原始模型文件。按每件器物的形状选择合适 UV 或投射方案，处理环绕接缝、顶部与底部聚拢、拉伸和转折接缝，保留清楚的肌理线条，避免明显镜像中线。效果图用于配色与工艺参考，不能把拍摄反光直接当真实材质反光。主体为喷涂在铜上的非金属漆面，露铜区域单独设置铜底色、金属度与粗糙度，柄叶及附件遮罩到实际交界，不能侵入主体。
>
> 同一个模型的不同配色归入纹样选项，不能重复建立器物。每件器物、每个纹样分别记忆密度；缩略图固定为第三个材质对应的第一个彩色纹样，完整取景、视觉大小相近；运行时不随密度或材质更新，不进行实时缩略图绘制。花瓶继续可展示各系列适合的纹样；前八项直接显示，其余收入省略号磨砂菜单，避免重复纹样。
>
> 沿用现有浅深主题、磨砂玻璃、统一圆角和动效节奏；图标和文字在各自控件或矢量框内水平垂直居中，不额外添加箭头。桌面悬停和点击、触屏点击、键盘与减少动态效果均可用。任意方向拖动旋转，速度适中，切换材质不改变姿态。保留本地纹理导入、PNG 保存和当前效果 GLB 导出。
>
> 完成桌面和触屏模拟自检，核对 UV、遮罩、颜色、缩略图、密度记忆、导入导出、菜单切换与离线运行，删除新引入的重复或无入口代码。交付电脑、安卓、苹果独立 HTML；苹果文件预览另附 USDZ。保留上一版；清楚说明真机尚未验证的部分，不部署网站、不封装应用。

## 日常操作

- 临时试纹样：在底部“＋”选择本地 PNG、JPG 或 WebP；调整密度后该器物与纹样会分别记忆。
- 临时试模型：在常规器物或水果派内选择“导入器物/水果”，优先使用纹理完整内嵌的 GLB。STL 可以导入形状，但无 UV，需要后续专门展开才能获得稳定精细贴图。
- 永久新增主菜单系列：提供素材并使用上面的提示词。页面当前没有“新建系列”的用户按钮，需要修改项目源码并重新生成三个离线 HTML；不能只把文件复制进文件夹。
- 模型准备：主体与柄叶等附件尽量分开；Gold_ 或 Accent_ 开头的材质名用于保留附件原材质。内嵌纹理，避免 GLTF 外链资源丢失。
- 配色说明：写明哪一项保留、替换或新增，哪些区域露铜，以及菜单顺序。多个版本使用清楚名称。

## 源码维护位置

- museum-web/artifact-library.mjs：模型名称、唯一 ID、顺序、路径、缩略图、初始姿态。
- museum-web/fruit-profiles.mjs 与 fruit-profiles.json：已有水果纹样的配色参数。全新工艺不能简单套水果配色，需要另行定义。
- museum-web/paint-finish.mjs：统一漆面默认参数，本地导入也沿用。
- museum-web/index.html、app.mjs、product.css：主菜单系列入口、面板和交互。目前分类入口为常规器物/水果派，新系列需同步注册新入口和分类分发，避免错误归入旧系列。
- museum-web/build-offline.cjs、build-safari.cjs：资源内嵌与三端 HTML 构建，增加资源后检查是否完整打包。

重复材质应该作为配色选项复用同一模型；新增系列不应复制整套查看器、菜单控制或材质系统。
