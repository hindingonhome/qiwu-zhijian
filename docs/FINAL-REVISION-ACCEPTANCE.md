# 物派 V1.2.1 · 综合修订验收

2026-10-23 交付核验。独立交付，不覆盖“选择反馈验收”等旧目录；未上传、发布或替换正式版。

## 验收重点

1. 桌面底栏小叉只在色球已选中且鼠标悬停时显示，单独悬停或单独选中不显示，移开隐藏。键盘选中聚焦与触屏点选保留删除入口。
2. 首选项中的表面编辑记录和派库管理撤销、重做按钮，磨砂提示包含Ctrl+Z、Ctrl+Shift+Z/Ctrl+Y。快捷键作用于当前指向或聚焦的历史区域。
3. 派库管理的添加与历史操作分组，留出明确间距，撤销/重做等宽排列，手机布局也检查。
4. 圆形盘子使用原图从顶面投射，不再自动四向镜像，方向保持正确；覆盖方式固定为顶面。程序纹样也采用顶平面。旋转、密度、偏移继续可调。
5. 盘沿窄圈纹样渐变为黄铜金色，并增加磨砂粗糙度过渡。主体纹样清晰，固定金色盘底不变。静态缩略图及iPhone原生模型同步更新。
6. 保留生成工具第一栏、图形导出、统一名称浮签、独立色栏、0.01密度、作品和派库。

## 操作建议

打开Desktop/物派.exe。选中色球后移开鼠标，再回到色球，检查小叉显示条件。打开首选项，指向撤销/重做看快捷键提示，操作表面记录并使用快捷键。

选圆形盘子，导入带文字或方向标记的非对称图片，检查只出现一张原图，不出现四块镜像。旋转至侧面查看盘沿软过渡，再看盘底金色。Documents的“盘子顶面验证.png”使用A/B/C/D测试图验证方向，测试字母不属于内置素材。

## 验证与边界

66项单元测试，26组浏览器回归，涵盖悬停与选中组合、触屏入口、快捷键提示和首选项路由、管理栏间距、盘子原图投射与金底、图形导出、生成、作品及既有功能。Windows实际交付EXE核验生成、图形选择、4096PNG、全部ZIP、GLB、派库与作品。离线HTML、Android包内资源及原签名核验。详细结果在Documents日志及JSON。

未进行Android/iPhone真机、Linux原生运行验证；Linux仅备用HTML。盘沿为不透明材质混合，不增加模型透明或模糊整幅纹理。单张PNG最高4096px，ZIP最高2048px且图片数据上限160MB。程序纹样PNG为平面切片，当前器物烘焙请用GLB。重要数据仍请另存PNG或自包含.wupai-work。

旧盘子作品有原始图片时可恢复原图；如果只保留已镜像合成的纹理，缺失原图无法自动还原。
