# 物派 V1.2.1 · 图形交互验收

2026-10-22。独立于上一份“纹样管理验收”，仅本地验收，未上传、发布或替换正式版。

## 本轮变化

- “保存与导出纹理”使用与总纹样库对应的磨砂材质球，点击蓝圈标记，并展示所选纹理名称与真实贴图预览。内置、导入、生成纹理均可选择；生成器当前设计也有独立色球。选择导出对象不会改变器物材质。
- 删除角标默认隐藏。鼠标停在色球约 650 毫秒显示，移开收起，移动经过不会立即弹出。触屏长按可调出，再点小叉；点其他位置或 Esc 收起。键盘 Tab 聚焦仍可删除。
- 保留每件器物独立底栏、生成记录持久保存、永久删除确认、单张 PNG、全部 ZIP、独立表面细节与 0.01 密度。

## 验收路线

打开 Desktop/物派.exe，观察底栏默认没有小叉。把鼠标停在任意色球上，等待小叉出现，再移开确认隐藏。触屏可长按尝试。

打开“纹样”，展开“保存与导出纹理”，点梨原配色或其他色球，检查蓝圈、名称及贴图预览同步；保存一张 PNG。生成并应用一张纹样，确认导出色球中出现新项，点选后预览相应纹理；全部 ZIP 仍包含所有已保存纹理。

## 验证

65 项单元测试。24 组浏览器回归，包括本轮材质球点选、名称与预览一致、PNG、默认隐藏小叉、鼠标停留与离开、触屏长按及手机布局；此前生成、ZIP、删除确认、竞态、作品、派库和模型金色部位继续回归。Windows 实际交付程序核验图形选择、4096 PNG、全部 ZIP 和既有功能。离线 HTML、Android 拆分资源与 APK 文件核对。

单张 PNG 最高4096px；ZIP最高2048px，超过160MB提示降低分辨率或逐张导出。内置三维程序纹样导出平面切片，当前器物UV及材质烘焙请使用GLB。SVG仅适用于生成器当前固定矢量设计。

未进行Android/iPhone真机和Linux原生测试，Linux仅备用HTML。Documents包含四页使用说明PDF、更新后的手册、截图、日志和实际EXE测试记录。根目录SHA256SUMS.txt为交付文件校验表。之前各验收目录均保留。
