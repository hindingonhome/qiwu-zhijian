# 物派 V1.2.1 · 纹样管理验收修订

2026-10-22。本轮独立交付，保留此前“独立色栏验收”与“纹理生成验收”；仅本地验收，未上传、发布或替换正式版。

## 本轮变更

1. 每件器物底栏色球增加小叉角标，移除只影响当前器物。原有纹样也可移除；从总纹样库选回即可恢复。若移除当前色球，自动切换到仍保留的色球，全部移除时清空纹样。
2. 生成工具最底部增加“已生成纹样”，沿用总库磨砂色球，点选可应用到当前器物。记录本机持久保存，删除须确认；确认后移除总库和各器物关联。取消不改变任何记录。此前按标准生成文件名保存的生成纹样也会显示。
3. 保存与导出纹理成为独立卡片，可选全部现有内置、导入和生成纹理，逐张保存 PNG、配色色卡或设计图，也可打包全部 PNG 和清单到 ZIP。当前固定矢量设计支持 SVG，栅格纹理与三维程序纹样不伪装为矢量。
4. 表面细节与总纹样库、纹样生成并列，保留旋转、偏移、连续纹样导出、表面质感、粗糙度、金属感和底色控件。
5. 保留上一版独立底栏、原配色默认、总纹样库完整列表、盘子金色底面和 0.01 疏密。

## 建议验收路线

打开 Desktop/物派.exe，选择苹果，移除底栏苹果原配色色球，观察当前显示回退；切换梨，确认梨自己的色栏不变。回苹果，在“纹样”的总库选回苹果原配色，确认底栏重新出现。

展开“表面细节”，确认它是独立栏目。展开“纹样生成”，生成并应用一次，在该工具最底部检查“已生成纹样”。取消一次删除，再确认一次删除，检查总库与当前底栏同步清理。删除前可保存独立作品或 PNG；已保存的自包含作品仍能打开。

展开“保存与导出纹理”，选择梨原配色、导入纹理或生成纹理分别保存 PNG；选择 1024 px 并点击全部 ZIP，检查清单与 PNG 数量。切换不同器物，不应改变总导出列表。

## 验证与边界

- 单元测试 65 项：包括默认色球移除、重开、重新添加、跨器物隔离、生成来源标记与目录删除、导出完整列表以及既有功能。
- 浏览器回归 23 组：新增角标移除、删除确认与取消、删除与撤销一致性、延迟解码与删除竞态、重开持久性、全部 PNG/ZIP、导出不改变当前材质、独立表面细节与手机布局；保留之前的密度、作品、模型库、金色盘底和纹理生成测试。
- Windows 实际交付 EXE、离线 HTML 和 Android 资源校验结果见 Documents 的日志与 JSON。
- 单张 PNG 最高 4096 px；全部 ZIP 最高 2048 px，预计图片数据超过 160 MB 时停止并提示降低分辨率或逐张导出，以避免手机内存过载。
- 内置三维程序纹样导出为相同场函数和颜色的平面切片，不等于任意器物的 UV 烘焙。当前模型 UV 与材质请通过 GLB 导出。
- 本机纹样库不包含于配置 JSON 和 .wupai 模型库备份；重要纹理请保留 PNG 或 .wupai-work 独立作品。
- Linux 仅备用 HTML；本轮未验证原生 Linux 和 Android/iPhone 真机。
