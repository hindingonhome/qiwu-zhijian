# 物派 V1.2.1 · 独立色栏验收修订

2026-10-22。本目录独立于“纹理生成验收”上一版，保留旧版本与数据；仅本地验收，未上传或替换正式版。

## 本轮重点

1. 每种水果首次选择时使用自身原配色纹样：芒果保留原图集，苹果、梨、火龙果等对应自身颜色；桃子使用此前唯一保留的落地色。底栏仍从铜、金之后开始显示该器物的彩色纹样。
2. 每件器物拥有独立底栏，包括原有纹样及在该器物上新增选用的纹样。给火龙果选用苹果纹样不会改变梨的底栏；返回火龙果时恢复自己的选择和疏密。
3. 顶栏“纹样”中的总纹样库始终保留完整内置预设。选择总库里的纹样只扩充当前器物底栏，不自动改动其他器物。
4. 新生成或导入的图片形成磨砂色球，最多显示五种主要颜色，加入总库和当前器物底栏，保存在本机数据库。切换到其他器物时，可从总库点选同一个色球以应用并加入其底栏。
5. 密度范围仍为 1–5，两处滑条步长均为 0.01，例如 1.37、1.58。疏密记忆、撤销和作品保存均保留小数；旧整数作品仍可读取。
6. “纹样与表面”和“纹样生成”采用一致的折叠玻璃卡：标题、辅助说明、圆角箭头、边框、内边距和手机布局统一。表面细节也使用圆角折叠箭头。
7. 等待导入时改选预设或原材质，较新的选择优先，旧导入不会随后覆盖它。纹样库写入失败时仍可在当前会话应用；素材完整的作品也可打开，并提示保存独立作品或 PNG。

## 验收路线

打开 Desktop/物派.exe，依次选火龙果、梨、苹果，观察各自默认贴图和底栏。打开“纹样”，给火龙果添加苹果纹样，调到 1.37；切到梨，确认仍为梨的默认配色，再返回火龙果，确认自己的选择被记住。

在“纹样生成”中生成一次并应用，观察总库和当前底栏出现新色球。切到圆形盘子，先观察其独立底栏，再从总库选新色球，检查顶面与固定金色盘底。重开应用，检查新色球和各器物底栏仍保留。保存一个 1.37 密度的作品，再打开确认数值与材质一致。

## 测试与构建

- 62 项单元测试：独立底栏状态、0.01 记忆与随机疏密、小数作品往返、金线、透明度、配色、模型库、导出与安全。
- 21 组浏览器回归：既有缩略图、切换、灯光、帮助、布局、模型库、盘底、作品、GLB；新增独立色栏、全局目录、持久色球、重开恢复和统一卡片。
- 专项故障测试：模拟纹样库写入配额错误，验证会话应用和自包含作品；延迟图片解码，验证旧导入不能覆盖新预设。生成工具后台失败回退、图片及参考图竞态继续覆盖。
- 离线与移动资源：验证独立 HTML、Android 分离资源的生成与色球流程；APK 中 JavaScript、纹样 gzip 二进制别名和盘子资源逐字节核对。
- 实际 Windows EXE：生成、应用、4096 PNG、1.37 密度、固定盘底、PNG/GLB、语言、派库备份与作品重启恢复。详细结果在 Documents/实际EXE测试.json。
- PDF：四页说明已更新并逐页渲染检查，含新底栏截图与 0.01 操作说明。

## 文件与数据

Desktop 为 Windows 便携应用及备用 HTML；Android 为原签名 APK 及备用 HTML；iPhone 包含网页及 26 个原生模型；Linux 本轮提供备用 HTML，未构建原生 AppImage。

Documents 包含 PDF、使用手册、变更记录、截图和测试日志。SHA256SUMS.txt 为本目录文件校验清单。

纹样库本机保存，配置 JSON 与 .wupai 模型库备份不包含该纹样库。跨设备保留重要纹理请使用 PNG 或 .wupai-work 作品；作品内含纹理数据。存储不可用的会话纹样需要在关闭应用前另行保存。

未进行 Android/iPhone 真机和 Linux 原生运行验证。浏览器测试在 Edge 及模拟触屏环境完成。未进行远程上传、发行或替换旧正式版本。
