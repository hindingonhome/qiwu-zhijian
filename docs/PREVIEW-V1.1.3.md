# 物派 V1.1.3 本地验收说明

状态：待用户验收，未上传GitHub。公开发行版仍为V1.1.2。

## 从哪里开始

- 电脑：进入Desktop，双击“物派.exe”，无需安装。建议在2K屏幕最大化，再调整为普通窗口对比。
- 网页备选：Desktop/Backup-HTML/Wupai.html，可直接用支持WebGL的浏览器打开。
- 安卓：Android/Wupai.apk，为同一应用标识及签名的可安装预览版。请按需备份设置后覆盖安装，不要先卸载。
- iPhone：iPhone/Wupai.html和Models模型包，沿用原方案，没有IPA。
- Preview-Images中有2K主界面、首选项菜单、深色主题和手机截图。

Linux原生AppImage将在确认后依原流程构建。本轮桌面视觉和共享网页已在多种窗口尺寸验证，未将自动化模拟称为全部平台真机验收。

## 本轮请验收：藏库与首选项

- [ ] 左上角说明卡随模型切换，可展开或收起；常规器物菜单不再显示大段介绍或资源路径。
- [ ] 顶栏“藏库”打开后，第一栏仍是水果派；默认内容不能删改，玻璃加号卡可导入自己的模型。
- [ ] “添加新派”创建栏目；默认锁定，解锁后才能导入、改名、编辑模型说明或删除。
- [ ] 增删后“撤销／重做”可恢复本次运行的最近20次操作。退出后撤销历史清空。
- [ ] 关闭并重新打开应用，自建栏目及模型仍在；重新打开后编辑锁恢复锁定。
- [ ] 首选项第一栏提供简体、繁体、英语。用户输入的栏目名和模型说明保持原样。
- [ ] 首选项内的展示、藏库管理、配置与备份均可折叠，灯光角度不再出现长串小数。
- [ ] 保存配置生成JSON，导入会合并栏目并恢复界面设置，保留现有模型。
- [ ] 完整藏库备份生成.wupai，含自建栏目、用户模型源文件与界面设置。恢复会替换个人藏库，可撤销。
- [ ] 手机、普通窗口、2K最大化时布局是否舒适；自建模型、内置水果及纹样切换是否顺手。

完整备份不包含本次导入的图片纹理、编辑材质、密度或相机姿态，不是完整三维工程。单模型100MB、个人源模型合计300MB；最多100个自建栏目和2000个模型。大量模型分批显示，自建模型用名称卡片避免实时渲染缩略图。

帮助和许可正文继续保留简体中文原文，界面三语切换不会改写授权条款。锁是防误操作开关，不是密码保护。请定期导出完整备份，清理浏览器或应用数据前先备份。
