# 物派 V1.2.1 · 选择反馈验收

2026-10-22。独立于上一份“图形交互验收”；仅本地验收，未上传或替换正式版。

## 本轮变化与验收方式

1. 打开纹样菜单，第一栏应为“纹样生成”，其后是纹样与表面、表面细节、保存与导出纹理。生成工具仍按需初始化，保留原有控件。
2. 内置、动态生成和导出色球的名称统一采用磨砂浮签；鼠标指向、键盘聚焦或点击均可显示。导出选中的名称和贴图预览继续保留。
3. 删除小叉不再等待0.65秒，指向或聚焦可删除色球时立即显示，当前选中的可删除色球保持显示；未选且移开后隐藏。触屏点选选中后即可删除。生成记录永久删除仍需确认，取消不丢失。
4. 在导出区选其他色球，器物底栏的选中标记与材质应保持不变。每器物独立色栏、所有纹理PNG/ZIP、作品和派库流程继续保留。

## 测试

65项单元测试、24组浏览器回归。专项覆盖即时角标、切换选中后的收起、磨砂名称与无系统title、动态生成纹理、导出PNG、首栏顺序、导出选择独立性和手机布局。离线HTML和Android资源版同样核验；Windows实际交付EXE验证生成、图形选择、4096PNG、全部ZIP、GLB、派库备份和作品重开。详细日志及实际EXE测试JSON见Documents。

Android APK保留原应用ID与签名。未进行Android/iPhone真机和Linux原生测试；Linux只提供备用HTML。单张PNG最高4096px，ZIP最高2048px且图片数据上限160MB；程序纹样导出为平面切片，当前器物UV及材质烘焙使用GLB。SVG仅用于当前固定矢量设计。

Desktop含Windows便携EXE及备用HTML，Android含签名APK及备用HTML，iPhone含网页与26个USDZ模型。Documents含使用说明PDF、更新手册、变更记录、截图和日志。SHA256SUMS.txt为逐文件校验表。此前验收目录保留。
