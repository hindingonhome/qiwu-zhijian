# 物派 V1.1.3 · 本地验收预览

尚未上传GitHub，待用户验收确认后才能正式发布。

- 顶栏采用悬浮液化玻璃表面，当前器物名称整合到顶栏，移除独立大标题及整片顶部遮挡。
- 收小底部纹样与播放控件，桌面合并成单行紧凑控制台。
- 大屏菜单为功能独立、宽度适中的玻璃面板；普通窗口与手机按断点独立适配。
- “说明与许可”放在顶栏“首选项”之后，底部不再重复占位。
- 新增本机个人藏库：可自建栏目、持久保存模型、编辑名称与说明；默认内容只读，解锁删改，20步会话撤销／重做。
- 首选项首组为简体／繁体／英语语言选项，展示、藏库和备份分组折叠；用户资料不自动翻译，许可原文保留。
- 提供JSON配置导入导出与含模型的.wupai完整备份，验证通过后提交，导入可撤销。
- 每件模型说明移至左上角玻璃折叠卡，默认说明按器型重写；修复灯光角度长小数。
- 自建模型复用有限解析缓存，大藏库按24件分批显示，安卓大文件分块导出。
- 保留原有器型、纹样、自由旋转、固定缩略图、密度记忆、本地导入、当前效果导出、灯光回退、浅深主题及非商业许可。

正式发布仍沿用四个平台ZIP、直接APK和SHA256SUMS.txt，需用户确认后再构建与上传。
