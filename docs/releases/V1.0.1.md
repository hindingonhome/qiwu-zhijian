# 器物之间 V1.0.1

按设备选择一个平台包即可；各包已包含使用说明与更新日志。

| 平台 | 下载 | 使用方法 |
| --- | --- | --- |
| 电脑 | [电脑平台包](https://github.com/hindingonhome/qiwu-zhijian/releases/download/V1.0.1/QiwuZhijian-1.0.1-Desktop.zip) | 解压后打开网页，Windows 也可用启动脚本 |
| 安卓 | [安卓平台包](https://github.com/hindingonhome/qiwu-zhijian/releases/download/V1.0.1/QiwuZhijian-1.0.1-Android.zip) | 包含安装 APK 与离线 HTML |
| iPhone | [iPhone 平台包](https://github.com/hindingonhome/qiwu-zhijian/releases/download/V1.0.1/QiwuZhijian-1.0.1-iPhone.zip) | 网页、25 个模型与打开说明已归档 |
| Linux | [Linux 平台包](https://github.com/hindingonhome/qiwu-zhijian/releases/download/V1.0.1/QiwuZhijian-1.0.1-Linux.zip) | 解压后运行 `sh Launch.sh` 或打开离线网页 |

安卓也可[直接下载安装 APK](https://github.com/hindingonhome/qiwu-zhijian/releases/download/V1.0.1/QiwuZhijian-1.0.1-Android.apk)。

本次更新：

- 下载附件由逐个模型展开改为四个平台包、安卓 APK 与校验文件，共六项。
- 手机端菜单改为留边的圆角磨砂浮层，统一卡片、按钮、弹出菜单和导入区域的圆角、间距与居中。
- 新增 Linux 离线浏览器版及启动脚本。
- 所有平台包包含 CHANGELOG.md，后续更新沿用同样的归档方式。

已检查平台归档完整性、签名和浏览器交互。未进行手机或 Linux 图形桌面真机测试。iPhone HTML 仍需要支持本地 JavaScript 与 WebGL 的浏览器，系统“文件”中的原生模型查看请使用 Models 文件夹。
