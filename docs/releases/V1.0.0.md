# 器物之间 V1.0.0

首个独立维护版本，基于已确认的固定缩略图与流畅切换版。

- 花瓶与 11 个水果器型、本地纹理和模型导入、PNG 与当前材质 GLB 导出。
- 固定第三材质彩色缩略图，密度按器物和纹样分别记忆。
- 共用调色板着色程序，减少逐水果重复编译。
- 铜底、漆面、附件遮罩、专用芒果 UV 图集及花瓶纹样。
- 灯光调节与恢复原版、统一磨砂 UI、居中图标、主题翻转。
- 桌面与手机 HTML、安卓签名 APK、iPhone USDZ 与 SHA-256 校验。

安卓导出使用系统文件保存窗口。iPhone 文件预览请打开 USDZ，HTML 需要支持 JavaScript 和 WebGL 的浏览器。尚未完成手机真机验收，首次载入大型模型仍可能短暂准备。
