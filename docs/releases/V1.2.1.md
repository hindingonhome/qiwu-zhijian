# 物派 V1.2.1

新增纹样生成、独立器物色栏、本机纹样库和可编辑作品；统一磨砂玻璃交互，新增圆形盘子及顶面投射和柔和盘沿。纹样生成置顶，表面细节与图形化纹理导出独立列出。

- 固定矢量4–6色、图像纹样4–7色，支持锁色、交换、参考取色和金线处理，生成后直接应用到不同器物。
- 每件器物保留自己的原配色与底栏，总库保留全部纹样；密度以0.01微调。
- PNG、GLB、独立.wupai-work作品与全部纹理ZIP分别导出；首选项可设置默认导出位置。
- 派库支持添加栏目与模型，齿轮改名和确认删除，复杂管理及恢复集中首选项。
- 修复纹样删除/导入竞态、盘子镜像拼接、历史快捷键作用范围和管理控件间距；更新使用说明、隐私说明及四页PDF。
