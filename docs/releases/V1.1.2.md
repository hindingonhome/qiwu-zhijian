# 物派 V1.1.2

本版优化桌面多分辨率，重点适配2560×1440，并继续包含V1.1.1的使用说明与许可。

- 大窗口中导航向两侧展开，字体、按钮、纹样球、卡片与面板适度放大，上限受控。
- 标题与大窗口底部控制区下移，模型展示中心随实际UI位置调整；默认取景按模型尺寸和可用空间适配。
- 手动调整窗口保留旋转姿态与缩放，只有重置视角或切换器型时重新取景。
- 帮助、导出、更多纹样、灯光和导入面板同步适配；保留小窗口、较矮窗口与手机布局。

## 下载

Windows选Desktop.zip运行物派.exe；Linux选Linux.zip执行sh Launch.sh；安卓安装APK；iPhone沿用HTML与Models内USDZ，无IPA。四个平台ZIP、直接APK与SHA256SUMS.txt共六个手动附件。
