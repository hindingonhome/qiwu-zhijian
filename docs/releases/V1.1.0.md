# 物派 V1.1.0

正式更名「物派」。全部平台统一墨黑浅金、放大圆角「物」字图标，字体轮廓来自源泉圆体，附带商业使用许可声明。

- Windows：解压 Desktop ZIP，运行「物派.exe」，无需安装。
- Linux：解压 Linux ZIP，运行 `sh Launch.sh` 启动物派 AppImage；可创建带图标的应用菜单入口。
- Android：安装 APK，保留原应用标识和签名，支持覆盖更新。
- iPhone：沿用离线 HTML 和 Models 内的25个 USDZ，不提供 IPA。
- 桌面包保留 Backup-HTML 网页备选。HTML 文件的系统图标由浏览器关联控制，网页页签已使用新图标。

固定缩略图、密度记忆、自由旋转、灯光回退和材质导出继续保留。

下载仍为四个平台 ZIP、直接 APK 和 SHA256SUMS.txt，共六项。
