# 物派 · Linux 免安装版

解压整个文件夹，在图形桌面的本目录终端执行：

```sh
sh Launch.sh
```

启动「物派.AppImage」，无需安装 Node.js。启动脚本使用 AppImage 解包运行模式，无需 FUSE。可选运行 `sh Create-Desktop-Entry.sh` 创建带「物」字图标的当前用户应用菜单入口。

备用网页版位于 Backup-HTML/Wupai.html。便携设置保存在应用旁的 Wupai-Data；目录不可写时使用系统用户数据目录。需要 x86_64 Linux 图形环境和可用的图形驱动。

操作说明见 User-Guide.md，更新记录见 CHANGELOG.md。自动化图形测试不等于全部 Linux 发行版真机验收。
