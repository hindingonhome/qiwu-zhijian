# 器物之间 · Linux 版

本包是离线浏览器版，适用于带图形桌面、支持 WebGL 的 Linux 系统，无需安装 Node.js 或运行网络服务器。

解压整个文件夹，双击 QiwuZhijian.html，或在本目录终端执行：

```sh
sh Launch.sh
```

启动脚本使用 xdg-open 调用系统默认浏览器。建议使用启用了硬件加速的 Chromium 或 Firefox。此包不包含 AppImage、deb 或系统安装服务。

操作说明见 User-Guide.md，更新记录见 CHANGELOG.md。尚未进行 Linux 图形桌面真机测试。
