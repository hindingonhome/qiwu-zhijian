# 物派 · Windows 免安装版

解压整个文件夹，双击「物派.exe」。无需安装 Node.js 或运行网站服务。应用图标使用墨黑浅金的圆角「物」字。

备用网页版位于 Backup-HTML/Wupai.html。HTML 文件在文件管理器中的图标由系统关联决定，浏览器页签和网页内标识使用物派图标。

应用未购买商业代码签名证书。下载后请核对发布页 SHA256SUMS.txt。便携设置保存在程序旁的 Wupai-Data；目录不可写时使用系统用户数据目录。

操作说明见 User-Guide.md，更新记录见 CHANGELOG.md。
