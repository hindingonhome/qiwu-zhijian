# 物派 V1.2.1 · 纹理生成验收更新

2026-10-22。本目录独立于上一份 V1.2.1；仅本地验收，未上传、未替换正式版。

## 主要改动

1. “纹样”中新增可折叠“纹理生成”。固定矢量提供 4/5/6 色，图像纹样提供 4–7 色。两份用户 HTML 的功能与来源审查见 Documents/纹理生成来源审查.md。
2. 支持改色、锁定、随机配色、拖动或两次点选交换颜色、参考图片取色。金线与边缘折叠区提供金线颜色、固定矢量加粗、图像智能/严格/宽松金线识别、关闭保护、透明金线与抗锯齿。
3. “生成并应用”把纯贴图导入当前器物，加入本次打开的纹样列表。透明金线在器物表面露出铜色与金属材质；柄叶、盘底与固定金色部件保留。生成后可保存 .wupai-work 作品继续使用，或导出 PNG 独立保存。
4. 保存区提供 PNG、配色色卡、设计图；固定矢量另提供 SVG。PNG 最长边可选 1024/2048/4096，DPI 为独立打印元数据，不等于像素尺寸。SVG 保留原始矢量路径精度。
5. 所有器物共用完整内置纹样目录，不再切换物体就减少。面板显示完整目录，底栏保留常用项和更多收纳；切换内置器物保留当前所选纹样。
6. 密度范围 1–5，按 0.25 细调，分别记忆器物与纹样。旧作品仍能读取原先 1–10 数值，重新拖动时采用新范围。
7. 自建栏目标题增加齿轮，包含解锁/锁定、重命名、删除。删除前确认，取消不删除；恢复仅在首选项中。默认栏目仍只读，底部整行“添加新派”和直接导入模型保留。
8. 固定几何按需加载，图像分析后台运行；后台不可用时可回退继续应用，较高导出分辨率按设备能力限制。异步导入具有请求序号，旧图片或参考图不会覆盖较新的选择。
9. 四页使用说明 PDF 已更新并逐页渲染检查，包含实际界面和纹理生成步骤。简繁英 UI 保留，用户模型名称不翻译。

## 建议验收路线

打开 EXE，在“纹样”展开“纹理生成”：调色，展开金线设置，勾选透明金线，生成并应用。切换圆形盘子和水果检查表面；试 1.25、1.5、2 的密度。导入一张自己的纹样图片，试参考图取色与金线识别，保存纯 PNG 和作品。随后在派库添加新派，用齿轮解锁改名，取消一次删除，再确认删除并到首选项撤销。最后检查手机网页与四页使用说明。
