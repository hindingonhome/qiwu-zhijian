# 物派 V1.2.1 本地验收说明

2026-10-21。本轮保留当前物派玻璃界面与操作习惯，先验收，尚未上传 GitHub。

## 本轮请重点验收

1. 派库按书架方式使用：底部保留整行带加号的“添加新派”。新栏目默认名称“新派”，每栏可直接导入模型，不要求解锁。
2. 派库只做浏览与添加。解锁、重命名、模型编辑、删除、撤销与重做全部在首选项“派库管理”；默认器物与水果派只读，灰色“内置”标签已去掉。
3. 圆角折叠箭头：展开朝下，收起转向右侧；尊重系统减少动态效果设置。
4. 色块采用扁平磨砂质感，从既有纹样配色中按占比选取最多五种主色，纵向平铺。仅调整界面图标，未改变材质算法或增加运行时缩略图渲染。
5. 首选项采用统一的折叠设置卡；模型管理按栏目展开并分批显示，按钮尺寸、间距和长名称换行已调整。
6. 常规器物新增圆形盘子：肌理仅在顶面，侧沿、底面及隐藏内折边固定为仿金漆黄铜。原模型不被覆盖，原拓扑保留；预处理只拆分材质并整理顶面 UV。
7. 首选项新增“导出位置”。桌面应用默认每次显示保存对话框，可选择默认文件夹后关闭每次询问；同名文件自动编号。目录设置仅保存在当前设备，不进入配置或备份。
8. 支持目录授权的浏览器可以选择默认文件夹；重启浏览器后可能需重新授权。不支持的浏览器使用下载设置，安卓使用系统文件选择器。界面按实际能力显示。
9. Documents 中附三页简明使用说明 PDF，可直接转发；各平台目录也放入同版说明与更新日志。

## 推荐验收路线

打开应用，选择常规器物中的圆形盘子，换纹样并翻转检查底面；在派库添加新派，直接导入模型；到首选项展开该栏目，解锁、改名、删除，再撤销。选择默认导出目录并导出 PNG，关闭重开后确认设置保留。最后检查小窗口、2K 最大化和手机网页的布局。

未进行远程上传、发行或替换旧正式版。正式发布仍按四个平台 ZIP、直接 APK 与 SHA256SUMS.txt 共六项整理。

最终交付核验：直接运行交付目录 Desktop/物派.exe，启动、隔离、模型切换、PNG/GLB、派库语言与备份、作品保存后重启恢复均通过。测试还核对了打包后的盘子顶面几何，确认包含最终底部内折边修正。Android APK 内盘子文件与开发源派生资源的二进制完全一致，签名校验通过。
