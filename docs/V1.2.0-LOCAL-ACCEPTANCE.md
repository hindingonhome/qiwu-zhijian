# 物派 v1.2.0 本地验收报告

日期：2026-10-21。此版供本地验收，尚未上传 GitHub，V1.1.3 保留。

## A. 技术栈与审查
原生 ES Modules、Three.js 0.180.0、Electron、Capacitor。先验证原有控件：加号导入纹理、滑块调自动旋转速度、三角形播放暂停、圆形按钮切换主题。保留这些含义及鼠标手势。

## B. P0 / P1
- 延续现有浮动玻璃顶栏、中央器物和底部胶囊，仅增加可收起的“调整”。
- 真实纹样疏密、原色/暖阳/清凉/柔和四种配色、“再试一次”改变疏密。
- 表面编辑撤销/重做，连续拖动合并为一步；切换器物开启新的编辑历史。
- 保存作品、打开作品、最近作品、独立 .wupai-work 文件。保存模型和图像源、材质参数及视图，可恢复编辑。
- 原材质模式也保留隐藏中的导入纹理；失败的作品打开回退原画面。
- 原有藏库 .wupai 备份保持兼容。作品与藏库是独立格式，作品需在最近作品中单独导出。

## C. 关键文件
新增 design-history.mjs、surface-editor.mjs、surface-palette.mjs、work-project.mjs、works-ui.mjs。app.mjs 接入现有流程；viewer.mjs/fruit-flow.mjs 仅扩展配色与缓存处理；responsive.css/i18n.mjs 适配。README、使用说明、更新日志与隐私说明同步更新。

专项验证覆盖真实画面变化、密度、配色、撤销、作品回读、自包含模型图像、损坏文件回退、原材质保留纹理、GLB 配色烘焙。

## E. 界面对照
不更换框架、不增加常驻侧栏、不重排原有导航。调整弹层按需打开；保存画面菜单增加作品保存/打开/最近作品。提示可收起。

## F. 限制 / P2
没有新增手绘、图层、照片生成、云同步、新纹样算法、模型结构编辑。再试一次只改变当前支持的密度，不虚构新算法。芒果原始图集维持密度 1；原材质及纯金属不显示无效配色操作。撤销记录在当前会话有效；持久保存请保存作品。

## G. 建议验收路径
打开 Desktop/物派.exe 或备用 HTML → 切换器物 → 点调整 → 换颜色/疏密 → 撤销 → 保存画面菜单保存作品 → 重开应用 → 最近作品恢复 → 导出作品文件并重新打开。
检查 2K 最大化、小窗口、手机竖屏，确认顶栏、底栏及弹层舒适。
验收通过之后再发布，Release 继续按四个平台 ZIP、直接 APK、SHA256SUMS 共六个手动附件整理。
