# 物派 V1.2.1 · 针对性代码自检与优化建议

2026-10-23 交付核验。范围：器物切换、图片应用/恢复、盘子投射与材质、GLB烘焙、纹样色球、快捷键、首选项管理布局、纹理导出与本机存储。结合源码检查、独立只读复核和自动回归；不代表所有平台或所有输入均已验证。

## 本轮已修复

1. **盘子出现对称拼接**：`assets/plate.glb`已有平面UV，但`app.mjs`对所有图片统一做四向镜像。盘子现使用原图，固定顶面UV，校正CanvasTexture垂直方向；程序纹样只使用顶平面。旧作品有原始图片时优先还原原图，防止恢复时再次使用旧镜像结果。
2. **盘沿纹样与黄铜边界太硬**：新增`plate-edge.mjs`，只从顶面实际引用顶点求边界，在约3.5%半径宽度内平滑混合为黄铜色并增加磨砂粗糙度。颜色在纹理采样后混合，金属感/粗糙度在其他遮罩处理后混合，底面独立金色材质不动。共享程序key不含密度，避免每次拖动重新编译。
3. **删除角标显示条件过宽**：`swatch-item.mjs`桌面条件改为选中且悬停；键盘聚焦与触摸输入另保留可达性，移动鼠标离开时隐藏。
4. **快捷键提示与实际范围不一致**：按钮增加磨砂提示、辅助快捷键标记；首选项内按当前指向/聚焦区域区分表面与派库历史，修复表面记录打开时Ctrl+Z误发到派库的问题。
5. **派库管理操作拥挤**：添加与历史组留空，撤销/重做等宽对齐，空管理容器不占行；验证按钮几何间距。
6. **派生资源过时**：静态盘子缩略图、iPhone原生盘子模型重新生成；准备脚本改为使用当前可见材质球入口。

## 已核查并保留的约束

- 盘底使用独立材质，编辑与导出不替换它；顶部UV不随手动旋转改变。
- 材质/模型缓存有数量上限；新羽化边界结果缓存于几何体，参数调整不重复遍历网格。
- 动态名称用textContent，删除生成记录仍需确认，旧导入异步解码不会重新绑定已删除纹样。
- 原始盘子模型保留，未改写来源文件；四个平台资料分包结构沿用；正式发布须通过平台构建和归档检查。

## 值得后续优化，但本轮未贸然重构

1. **纹理ZIP流式输出**（`texture-export.mjs`）：现按张渲染、有160MB保护，但最终ZIP仍同步组包，大图库在低内存设备可能短暂停顿。可改流式打包/输出，并增加取消任务和真实低内存机测试。
2. **统一器物表面规则**（`app.mjs`、`viewer.mjs`）：盘子的投射、图片方向与恢复规则分布在几处。可逐步收拢为器物表面配置，在覆盖旧作品和导出回归后再迁移，避免一次性重构破坏现有习惯。
3. **羽化像素与导出基准**：目前有非对称图、底面/GLB与截图验证。可增加黑色和透明纹理的盘沿像素阈值基准，以及导出后同视角对比，减少未来着色器叠加顺序回归。
4. **材质增量更新**（`viewer.mjs`）：缓存有上限，但完整参数快照仍作为材质签名。进一步区分几何/程序变化和仅uniform变化可减少对象分配；需要先测量实际收益。
5. **发布文档已去重**：现行手册统一为正式V1.2.1说明，历史只留CHANGELOG；隐私说明同步纹样持久保存。浏览器测试改为默认Chromium，避免Linux CI错误依赖Edge。

## 验证边界

本轮运行66项单元测试、26组浏览器回归，另验证实际Windows交付EXE、离线网页、Android包内资源及签名。Android/iPhone真机、Linux原生运行和大规模低内存压力测试仍未进行。完整证据见同目录测试日志与JSON。
